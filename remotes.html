Remotes

Each Harmony model stores its setup differently, so each one is added on its own and tested on real remotes before it's called supported.

  • Supported In every release and tested on real remotes.
  • Experimental Works, but few people have tried it yet. Please report how it goes.
  • Beta In a public test build on the download page, not yet in a release.
  • Testing Being tried privately with volunteers on Discord; not in any download yet.
  • Planned Not usable with Afterglow yet.

Point at a remote to take a closer look. Click it for the details.

Harmony 900 Supported

2009 · touchscreen remote with RF blaster

Everything you could set up with Logitech's software:

  • Devices and activities, including which device each button controls in an activity
  • Every physical button, and the power plan: what turns on, in what order, and what turns off
  • Input switching and channel entry for each device
  • IR output per device: the remote's own emitter, or the RF blaster and its two mini emitters; new blasters can be paired
  • Remote settings and the icons the remote shows

Harmony 1100 Experimental

2009 · 3.5-inch touchscreen

Afterglow reads, imports and builds 1100 configurations, and writes them only through Test write, which backs the remote up first and checks the result.

  • Both boards and both model numbers are recognised
  • Checked against the 1100's own firmware, versions 6.9 to 7.7
  • Few people have tried it yet: please tell us how it goes

Harmony One Experimental Testing

2008 · touchscreen remote

Afterglow already sets up real Harmony Ones. It's being tested privately with volunteers first, then comes to a public beta, then a release.

  • Own a One? Join the Discord and ask to become a tester.

Harmony 800 Planned

2012 · touchscreen and slide-out keyboard

Support for the 800 is planned. It talks to the computer differently from the 900 and stores its setup in its own format, so it needs work of its own. It can't be set up with Afterglow yet.

Harmony 650 Planned

2010 · colour screen

Support is planned. It can't be set up with Afterglow yet.

Harmony 880 Planned

2005 · colour screen and charging cradle

Support is planned. It can't be set up with Afterglow yet.

Another Harmony?

Other models aren't supported. If you own one, a backup of its configuration and an evening of testing are the two things that help most. Say hello on Discord ›
